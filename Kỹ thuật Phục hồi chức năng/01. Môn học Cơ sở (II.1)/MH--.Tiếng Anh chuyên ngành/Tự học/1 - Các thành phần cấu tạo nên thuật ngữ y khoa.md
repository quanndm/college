Có 4 thành phần cấu tạo nên thuật ngữ y khoa
- Gốc từ (root word)
- Dạng kết hợp (combined form)
- Tiền tố (Prefix)
- Hậu tố (Suffix)
## 1.  Gốc từ
- Cung cấp ý nghĩa căn bản của thuật ngữ
- Thường chỉ bộ phận cơ thể người
- Không bao giờ đứng 1 mình 
- Ngoại trừ:
	- **Cardi-** : gốc từ chỉ **tim**
		- Cardiologist: Nhà tim mạch học
	- **Leuk-** : gốc từ chỉ **màu trắng**
		- Leukocyte: thuật ngữ chỉ bạch cầu


## 2. Dạng kết hợp
- Là dạng biến đổi của gốc từ 
	- **Cardi-**  =>  Cadi/o + **-logist** => Cadiologist
	- **Leuk-**  => Leuk/o + **-cyte** => Leukocyte



## 3. Tiền tố
- Luôn đứng đầu trong thuật ngữ y khoa 
- Khi được viết 1 mình thì có 1 dấu gạch nối theo sau 
- Thường biểu thị cho :
	- **Thời gian:** 
		- **Pre-**  => Pre-natal: thời gian trước sinh
	- **Vị trí:**
		- **Sub-** => Sub-arachnoid: dưới nhện (dưới màng nhện)
	- **Số lượng:**
		- **Di-**  => Di-sulfur: 2 lưu huỳnh
	- **Mức độ:**
		- **Macro-** => Macro-cytic: Tế bào lớn (khổng lồ) 
	- **Tình trạng:**
		- **Dys-** => Dys-pnea: Khó thở

## 4. Hậu tố 
- Luôn luôn đứng cuối
- Khi hậu tố đứng 1 mình thì có 1 dấu gạch nối ở phía trước
- Thường biểu thị cho:
	- Thủ thuật:
		- -scopy => Arthro-scopy: thủ thuật nội soi khớp
	- Rối loạn:
		- -algia => Gastr-algia: rối loạn (đau) dạ dày
	- Bệnh tật:
		- -itis => Rihn-itis: Viêm mũi
